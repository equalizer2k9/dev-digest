## Checked and clean

- **vendor/shared:** `server/src/vendor/shared/contracts/brief.ts` and `client/src/vendor/shared/contracts/brief.ts` have the same `BlastDegradedReason` and `BlastRadiusResponse`. The `BlastRadius`, `ChangedSymbol`, `BlastCaller` and `DownstreamImpact` shapes are also identical in both.

It reaches data through `container.reviewRepo` and `container.repoIntel`. `blast/helpers.ts` is pure.
- **Facade:** `repo-intel/service.ts:220-237` keeps the degraded/reason verdict in the facade. It adds no cross-module imports, and blast calls it once.
- **Wiring:** `modules/index.ts:12,38` has one import and one register line, as the convention requires.
- **Client component folder:** `_components/BlastRadius/` has `BlastRadius.tsx`, `index.ts`, `constants.ts`, `helpers.ts`, `styles.ts`, plus tests beside the subject. There are no invented sibling files.
- **Client component code:** the component imports UI only from the `@devdigest/ui` barrel (`SectionLabel`, `Skeleton`). Colors use only CSS vars. It is presentational, so the fetch lives in `OverviewTab` through the `useBlastRadius` hook.
- **Showcase and docs:** `Showcase.tsx:58,383-391` and `showcase/constants.ts:90` show the component, and `Showcase.tsx:56-62` already imports route-private components, so that is an existing convention. `client/specs/pages.md:297,318` is updated.

There is no `console.log`, `console.info` or `process.stdout` anywhere. `index.ts:20` logs with `console.error`. Files are kebab-case with one tool per file and tests beside the subject.
- **AGENTS.md budgets:** root `AGENTS.md` is 79 lines (≤ 80) and `devdigest-mcp/AGENTS.md` is 44 lines (≤ 60).
